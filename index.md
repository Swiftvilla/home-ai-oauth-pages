# Home AI - Google Drive Backup

A personal cloud backup application used to maintain an additional copy of files in Google Drive.

## About

Home AI - Google Drive Backup is a privately operated backup integration using Rclone.

The application transfers backup files from personal storage to Google Drive to provide an additional off-site copy.

It is not a commercial service and is not offered to the general public.

## Google Drive Access

The application uses Google OAuth 2.0 to authenticate with Google Drive.

It requests access to files created or authorised through the application, allowing it to upload, verify and restore backup data.

## Privacy

The application is intended for personal use. Backup data is not sold or shared with third parties by the application operator.

See the [Privacy Policy](privacy.html) for more information.
