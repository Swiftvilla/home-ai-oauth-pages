# Privacy Policy

**Application:** Home AI - Google Drive Backup

**Last updated:** 1 November 2026

## Overview

Home AI - Google Drive Backup is a personal, self-hosted backup application operated using Rclone and Google Drive.

It is intended exclusively for personal use and is not offered as a commercial service.

## Information Accessed

The application uses Google OAuth 2.0 to access Google Drive.

It requests permission to create, upload, read, verify and manage files created or authorised through the application.

The application does not request unrestricted access to all existing Google Drive files.

## How Information Is Used

Google Drive access is used solely to maintain and restore personal backup files.

Backup operations are performed using self-hosted infrastructure. Files are transferred to the account owner's Google Drive storage.

## Data Sharing

The application operator does not sell personal information or intentionally share backup data with third parties.

Google processes data as the storage and authentication provider, subject to its own privacy policies.

## Data Retention and Deletion

Backup files remain in Google Drive until removed by the account owner or by configured backup retention operations.

The account owner can delete stored files directly through Google Drive and revoke the application's access through Google Account security settings.

## Security

OAuth credentials and authentication tokens are stored on privately managed infrastructure and are not published in the application's public GitHub repository.

## Google API Services User Data

Information obtained through Google APIs is used only for the personal backup functionality described above and is not used for advertising or unrelated purposes.

## Contact

For questions about this application or its privacy practices, contact the application operator through the GitHub repository associated with this website.
